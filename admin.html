Cette page n’est pas liée depuis le site. Le jeton reste sur cet appareil et ne part que vers api.github.com.

Créer le jeton GitHub

  1. Sur l’iPhone, ouvre github.com et connecte-toi avec @farahei-create.
  2. Va dans Settings → Developer settings → Personal access tokens → Fine-grained tokens, ou ouvre la page de création.
  3. Nom : Onrecord. Expiration : 90 jours, ou la durée que tu choisis.
  4. Resource owner : farahei-create.
  5. Repository access : Only select repositories → cartographie-gaza-extreme-droite.
  6. Permissions → Repository permissions → Contents : Read and write. Laisse le reste sur No access.
  7. Generate token. Copie le jeton (il commence par github_pat_). GitHub ne le réaffichera pas.
  8. Colle-le ci-dessous. « Se déconnecter » l’efface de cet appareil.

Règles

  • Citation exacte, datée, avec une URL qui contient la phrase. Les crochets [ ] marquent une coupure.
  • Ton neutre. Pas de jugement sur la personne.
  • Pas de personne privée : personnalités publiques et organisations seulement.
  • Le contexte et le démenti vont dans la même fiche.
  • Wikipédia ne peut pas être la seule source.
  • Vidéo : seulement le compte du diffuseur d’origine ou un compte officiel.
  • Photo : Wikimedia Commons (CC BY, CC BY-SA, CC0, domaine public) ou portrait officiel réutilisable, avec auteur, licence et lien. Sinon, laisse la photo vide : le monogramme s’affiche.
Personnalité

Photo facultative. Depuis la galerie : elle est réduite à 400 px et convertie en WebP. Laisse vide pour le monogramme.
